# Libreta de Detective (Clue)

Hoja de "Notas del Detective" para jugar Clue desde el celular.

Abre `index.html` en el navegador o publícala con GitHub Pages.

- Toca una casilla: ✗ no la tiene → ✓ la tiene → ? sospecha → vacía
- De 2 a 6 jugadores, con nombres editables
- Las marcas se guardan en el navegador (localStorage)
